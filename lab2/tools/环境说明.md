## 1. PlantUML（本地渲染，不依赖外网）

| 组件 | 版本 | 路径 |
|---|---|---|
| OpenJDK | 21.0.2（华为镜像 zip，便携解压） | `tools/jdk21/` |
| PlantUML | 1.2025.10（阿里云 Maven 镜像） | `tools/plantuml.jar` |
| 启动包装 | — | `tools/plantuml.cmd`、`tools/plantuml.ps1` |

### 用法

```bat
:: 单张，输出 PNG（与 .puml 同目录同名）
lab2\tools\plantuml.cmd -charset UTF-8 -tpng "lab2\UML\UML类图.puml"

:: 批量：把 UML 目录下所有 puml 都渲染成 png
lab2\tools\plantuml.cmd -charset UTF-8 -tpng "lab2\UML\*.puml"

:: 只检查语法（不产图，适合流水线里的自动校验）
lab2\tools\plantuml.cmd -charset UTF-8 -checkonly "lab2\UML\UML类图.puml"
```

PowerShell 里如果直接运行 `.ps1` 被拦，用：

```powershell
powershell -ExecutionPolicy Bypass -File "lab2\tools\plantuml.ps1" -version
```

### 已验证

- `java -version`：OpenJDK 21.0.2 ✅
- `plantuml -version`：1.2025.10 ✅
- 中文类图渲染：`tools/smoke.puml` → `tools/smoke.png` ✅（含中文类名、属性、注释、多重性）
- 语法检查：`-checkonly` 返回 0 ✅
- 从 `C:\` 等任意工作目录调用包装脚本均可出图 ✅

> **已修的一个坑**：本机系统临时目录 `C:\Users\...\AppData\Local\Temp` 不可写，Java 的 ImageIO 会刷一堆 `AccessDeniedException`。
> 包装脚本已把 `java.io.tmpdir` 指到 `tools/tmp/`，现在出图无异常。
> 如果你绕过包装脚本直接 `java -jar`，记得加 `-Djava.io.tmpdir=...`。

### 关于 GraphViz

**不需要装。** 本机没有 GraphViz，但 PlantUML 自带 Smetana 布局引擎，在 `.puml` 开头加一行：

```plantuml
!pragma layout smetana
```

类图、组件图、状态图、部署图都能正常出图（已实测类图）。时序图、活动图（新语法）本来就不依赖 GraphViz。
如果后续某张图布局不理想，再考虑装 GraphViz（安装包在 `tools/downloads/` 之外可另取，非必需）。

### 中文与清晰度建议

```plantuml
skinparam defaultFontName "Microsoft YaHei"
skinparam dpi 200
skinparam shadowing false
skinparam backgroundColor #FFFFFF
```

- `.puml` 一律保存为 **UTF-8 无 BOM**，否则中文可能乱码。
- `dpi 200` 打出来约 1.5–2 倍尺寸，报告里缩放后仍清晰。
- 单张图宽度建议 1600–2400 px；太宽就拆图，不要靠缩小字号塞进去。

## 2. Pixso（UI 设计工具）

| 项 | 值 |
|---|---|
| 版本 | 2.3.1（官方 Windows 客户端） |
| 程序位置 | `lab2/tools/Pixso/Pixso.exe`（便携解压，478 MB） |
| 快捷方式 | 桌面 `Pixso.lnk`、开始菜单 `Pixso.lnk`、`tools/Pixso.lnk` |
| 安装包留存 | `tools/downloads/Pixso_win_v2_3_1.exe`（124 MB） |

### 为什么是"解压版"而不是走安装向导

1. 官方安装包是 NSIS，静默安装 `/S` 在本机会被 SmartScreen 拦下，且当前会话没有可交互的桌面，点不了"仍要运行"。
2. 安装包内部就是一个 `app-64.7z`，用 7-Zip 解出即为完整 Electron 程序，功能不依赖注册表。
3. 因此采用"解压 + 快捷方式"的方式，不写系统目录、不需要管理员，卸载时删目录即可。

如果你想要"正规安装"（带卸载项、文件关联），双击 `tools/downloads/Pixso_win_v2_3_1.exe`，在弹窗里点"更多信息 → 仍要运行"，按向导装一遍即可；两者不冲突。

### 使用前提

- Pixso 需要**登录账号**（微信/手机号）才能新建云端文件；首次打开按提示登录。
- 需要联网。离线只能看不能协同。
- 本会话里**任何 GUI 程序都无法保持运行**（连记事本启动后都会被系统结束），所以不要指望我在这里截图验证窗口；你双击桌面图标即可。

### 与课程要求的对应

课程允许"亿图图示、Figma 或 Pixso 等"。本机 Figma 官网超时、Lumence 不通，Pixso 可正常下载与登录，故选 Pixso。
报告里如实写"使用 Pixso 2.3.1 完成界面设计"即可；如果最后界面图由代码生成，也要在报告中说明工具链，不能假称是 Pixso 画的。

## 4. 已知限制（写报告/排期时要考虑）

1. **不能在本会话里开 GUI**：Pixso 的界面操作必须你本人完成，或者我们用代码生成界面图（Pillow/HTML），Pixso 只作为"设计工具合规"的补充。
2. **PlantUML 用本地 JDK**：换电脑时把 `tools/` 一起拷走即可，不依赖目标机装 Java。
3. **字体**：中文用系统自带微软雅黑；换到没有该字体的机器上，把 `defaultFontName` 改成 `SimHei` 或 `Noto Sans CJK SC`。
4. **路径含中文**：当前工作区路径有中文，Java/PlantUML 实测正常；包装脚本已用 `%~dp0` 相对路径，避免写死中文绝对路径。
