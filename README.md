## 文件说明

| 文件 | 内容 |
|---|---|
| `requirements.md` | 需求规格说明。每条需求含类型、来源、优先级、状态、描述、前置条件、正常结果、异常或边界情况、验收方法、关联需求十个字段；"来源"引用 `chat.txt` 中的访谈编号。 |
| `chat.txt` | 全过程原始记录，分三部分：访谈与补充沟通（`INT-xx-Lxxx`）、AI 交互记录（`AI-xx-Lxxx`）、人工审查记录（`REV-xxx`）。 |

## 版本标签

| 标签 | 含义 |
|---|---|
| `lab1-ai-draft` | AI 第一次生成的需求初稿（未经人工修改），以及当时的访谈与 AI 交互记录 |
| `lab1-final` | 人工审查、修改、补充跟进沟通后的最终版本 |

`lab1-ai-draft` 之后对 `requirements.md` 的所有修改，均可在两者之间的 diff 中追溯；
每条修改在 `chat.txt` 的"人工审查记录"里有对应的 `REV-xxx` 条目。

## 说明

本实验只做需求分析，不包含软件实现。需求中的"待确认"项均有明确出处，
经第二轮跟进沟通（`INT-02`）确认的部分已更新为"已确认"，仍无法确认的部分保留"待确认"并注明原因。
